## 각 챕터 공통 구조

모든 MBTI 유형 챕터는 다음 흐름을 따릅니다:

```
1. 도입 — "이게 나야" 공명 장면
   → 해당 유형이 일상에서 겪는 구체적 상황/고민

2. 유형 탐구 — "왜 나는 이럴까"
   → 해당 MBTI 유형의 인지 기능과 핵심 욕구/두려움

3. 불교의 질문 — "불교는 이렇게 본다"
   → 유형의 고통 구조와 연결되는 불교 개념 소개
   → 쉬운 언어, 일상 예시로 풀어쓰기

4. 만남 — "이 둘이 만나면"
   → MBTI 유형의 강점이 수행의 입구가 되는 방식
   → 유형의 약점이 불교적 처방으로 보완되는 방식

5. 실천 — "오늘 할 수 있는 한 가지"
   → 해당 유형에게 맞춤화된 작은 수행/마음챙김 제안
```
